## Featured Projects

### [Interpretable Credit-Default Modeling](https://github.com/MichalTalalaj/Interpretability-and-Callibration-of-a-high-risk-model)

A reproducible machine learning study comparing regularized logistic regression and XGBoost for credit-default prediction on imbalanced financial data.

Includes nested cross-validation, probability calibration, model evaluation, and explainability analysis using SHAP, LIME, and Partial Dependence Plots.

### [Steam Game Recommendation System - Bachelor's Thesis](https://github.com/MichalTalalaj/Thesis-Implicit-ALS-Confidence)

Research on how different confidence functions influence recommendation quality in implicit-feedback Alternating Least Squares (ALS), using Steam user interaction data.

Developed an experimental pipeline involving hyperparameter optimization with Optuna, sensitivity analysis, and statistical testing to evaluate recommendation quality and improvements over baseline approaches.

### [BiKing - Environment-Aware Cycling Route Planner](https://github.com/karabowiczjakub/larpathon)

A team project developed at **HackYeah 2026**, helping cyclists in Kraków compare routes based on shade, air pollution, and thermal comfort.

My contribution focused on functional testing, identifying implementation errors, and validating application behavior during development.
